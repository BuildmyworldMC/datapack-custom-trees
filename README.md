# Datapack Custom Trees - Edition Buildmyworld

Version supportée :

- 1.21.0 - 1.21.1

# Commande pour l'utiliser

Bouleau personnalisé

`/give @s birch_sapling[custom_name='{"color":"dark_purple","italic":false,"text":"Custom Birch"}',custom_data={custom_tree:1b},enchantment_glint_override=true] 1`

Bouleau vanilla personnalisé

`/give @s acacia_sapling[custom_name='{"color":"gold","italic":false,"text":"Custom Vanilla Birch"}',custom_data={custom_tree:1b},enchantment_glint_override=true] 1`

Ajouter `/minecraft:` devant la commande give sur serveur (spigot, paper, etc)
